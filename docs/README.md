## Choosing a guide

- Use the root README for the current quick start, API surface, MCP discovery,
  configuration reference, and compliance boundaries.
- Use a translated guide for orientation, then check the root README before
  configuring a newer release.
- To improve a translation, open a pull request that keeps its links and
  examples aligned with the root README.
