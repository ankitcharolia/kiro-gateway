# Code of Conduct

Kiro Gateway aims to be a welcoming, technically rigorous open-source project.
Everyone who participates is expected to help maintain a respectful environment.

## Expected behaviour

- Be respectful, constructive, and specific when discussing code or ideas.
- Assume good intent while asking for evidence and reproducible examples.
- Welcome contributors with different backgrounds, experience levels, and
  communication styles.
- Keep reports, reviews, and discussions focused on improving the project.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, doxxing, threats, deliberate
secrets exposure, and disruptive or bad-faith participation are not acceptable.

## Enforcement

Project maintainers may edit, remove, or close contributions and may restrict
participation when necessary to protect the community. Report conduct concerns
privately through the [maintainer's GitHub profile](https://github.com/ankitcharolia)
with enough context to investigate. Do not include private credentials or
security-sensitive details in a public issue.
